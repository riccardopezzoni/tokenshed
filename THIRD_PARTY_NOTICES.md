# Third-Party Notices

TokenShed currently has no third-party runtime package dependencies.

It uses:

- Swift standard library
- Foundation
- SwiftUI
- AppKit
- Apple platform frameworks available on macOS

Optional external tools and services are user-installed:

- Ollama, when the user chooses to use local open models.
- Codex and Claude Code, when the user configures agent integrations.
- Homebrew, when the user installs the CLI through a tap.

Those projects are governed by their own licenses and policies.
